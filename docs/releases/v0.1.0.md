First version, for Paper 26.1 and up.

- `/bug <what happened>` saves a private note with where the player was, which way they faced, their game mode and the time, to `plugins/Fieldnotes/notes.log`.
- For players with `fieldnotes.watched`, the last 80 actions are kept and saved every 5 seconds, when they leave (with how they left), when the server stops, and from a hook as Java exits. A hard kill can't be caught.

Tested: unit tests, and bots on a copy of a real server on Paper 26.2 and 26.3 build 249. Not yet used in a real game client.
